# Генеральный план: «Зайка ОС 1.0 (Media & Game Edition)»
## Полный реестр проблем и исчерпывающий план их устранения

---

## ЧАСТЬ 1. Полный реестр всех выявленных проблем и их первопричины

| № | Проблема | Симптом | Техническая первопричина |
|---|---|---|---|
| **1** | **Постоянный запуск как Live USB** | Диск пуст, при каждом перезапуске система разворачивается с нуля, настройки сбрасываются | В меню GRUB по умолчанию стоял пункт `livem` (Live Mode) вместо автоматической записи на жесткий диск `/dev/sda`. |
| **2** | **Критическая задержка загрузки (6+ мин)** | Долгий черный экран или экран ожидания при каждом старте | В скрипте `zaika_setup.sh` синхронно вызывался `pm install` для 4 тяжелых APK (AmneziaVPN 85MB и др.). Одно ядро CPU компилировало их через `dex2oat` более 6 минут. |
| **3** | **Экран «Запуск Android...» вместо ОС** | Отображается экран AOSP с полосой загрузки и чужим названием | Компонент `FallbackHome` из `Settings.apk` запускается системой, когда в PackageManager нет ни одного готового доверенного Home-лаунчера. |
| **4** | **Мышь не кликает ни по одной плитке** | Окно лаунчера видно, курсор ходит, но клики игнорируются | Слой `KeyguardScrim` (экран системной блокировки SystemUI) висит поверх всего экрана (`mCurrentFocus=KeyguardScrim`), перехватывая 100% кликов. |
| **5** | **Оконный режим DecoView (`_ [ ] X`)** | Лаунчер открылся в маленьком плавающем окне с серой шапкой на черном фоне | PrimeOS принудительно оборачивает любые пользовательские приложения из `/data/app` в оконный контейнер Freeform/DecoView. |
| **6** | **Отсутствие классического Рабочего стола** | Нет возможности переключиться в режим ПК | Родной `Launcher3` ранее просто отключался через `pm disable`, лишая пользователя многооконного десктопа. |
| **7** | **Упоминания «PrimeOS» и «Android»** | Логотип PrimeOS на кнопке «Пуск», название системы в свойствах и окнах | В `build.prop` и ресурсах `SystemUI.apk` не были заменены графические ассеты (кнопка Пуск) и текстовые дескрипторы. |
| **8** | **Установка без клавиатуры (только мышь)** | Требование исключить любые диалоги разметки и подтверждения | Для неттопа без клавиатуры разметка `sfdisk`/`mkfs.ext4` и установка GRUB должны происходить абсолютно автономно за 3-5 секунд по таймеру. |

## ЧАСТЬ 2. Архитектура двух интерфейсов («ТВ-приставка» и «Рабочий стол»)

По ТЗ в системе должно быть **два полноценных режима**, мгновенно переключаемых в один клик мыши:

```mermaid
flowchart LR
    A[Загрузка Зайка ОС с диска sda] -->|По умолчанию| B[Режим ТВ-приставки: LtvLauncher]
    B -->|Клик на плитку 'Рабочий стол'| C[Режим ПК: Десктоп Зайка ОС]
    C -->|Клик на ярлык 'ТВ-режим' / Меню Пуск| B
```

1. **Режим по умолчанию — «ТВ-приставка» (LtvLauncher):**
   - Запускается на весь экран **без рамок окна DecoView**.
   - Крупные плитки под мышь: 🎬 Фильмы (HDrezka), ▶ YouTube (SmartTube), 🎮 Игры, 🌐 Браузер, ⚙ Настройки, 🖥 **Рабочий стол**.
2. **Второй режим — «Рабочий стол Зайка ОС» (PrimeOS Desktop / Launcher3):**
   - Многооконный режим для мыши с нижней панелью задач.
   - **Кнопка «Пуск»:** замена логотипа PrimeOS на иконку мордочки зайки.
   - **Обои рабочего стола:** фирменный фон «Зайка ОС».
   - **Ярлык на рабочем столе и в меню:** «📺 ТВ-режим» для мгновенного возврата в LtvLauncher.

## ЧАСТЬ 3. Детальный план пошаговых исправлений

### Шаг 1. Перевод на 100% автономную установку на диск (`/dev/sda`)
1. **Конфигурация GRUB на носителе (`grub.cfg`):**
   - Пункт по умолчанию: `set default="0"` — **«Тихая установка Зайка ОС на диск /dev/sda»**.
   - Таймер автозапуска: 3 секунды.
2. **Скрипт тихой установки (`01-zaika-os.sh`):**
   - Автоматически удаляет Windows и любые разделы на `/dev/sda`.
   - Создаёт разметку (MBR/GPT) с разделом ext4 на весь диск.
   - Устанавливает файлы ОС (`system.sfs`, `kernel`, `initrd.img`).
   - Настраивает постоянный раздел `/data` на жестком диске.
   - Устанавливает GRUB в MBR диска `/dev/sda` со стандартной загрузкой Зайка ОС (таймер 1 сек).
   - Выдаёт команду безопасной перезагрузки / выключения.

### Шаг 2. Ликвидация задержки 6 минут и «Запуск Android...»
1. Все вторичные приложения (`SmartTube`, `HDrezka`, `AmneziaVPN`) устанавливаются **асинхронно в фоне** (`pm install ... &`) после старта графического интерфейса.
2. `LtvLauncher` внедряется как нативный доверенный лаунчер, благодаря чему Android не показывает экран `FallbackHome`.
3. Время загрузки системы с диска составляет **5–10 секунд**.

### Шаг 3. Разблокировка мыши (Устранение `KeyguardScrim`)
1. На уровне инициализации системы прописываются параметры в базы настроек:
   ```sh
   settings put secure lockscreen.disabled 1
   settings put global device_provisioned 1
   settings put secure user_setup_complete 1
   ```
2. Отключаются фоновые экраны первичной настройки:
   ```sh
   pm disable com.android.settings/.FallbackHome
   pm disable com.google.android.setupwizard
   ```
3. **Результат:** Невидимый слой блокировки `KeyguardScrim` никогда не активируется, фокус окна принадлежит интерфейсу, клики мыши работают сразу.

### Шаг 4. Нативный запуск ТВ-лаунчера без рамок окна DecoView
1. Чтобы PrimeOS не открывала ТВ-лаунчер в плавающем окне с серой полосой `< _ [ ] X`:
   - Добавляем пакет `com.leanbitlab.ltvL` в системный белый список полноэкранных приложений (`/system/etc/decoview_whitelist.xml` / `system/etc/freeform_blacklist.xml`), либо прописываем флаг `ro.prime.fullscreen_apps`.
   - Альтернативно: выставляем пакету LtvLauncher системную категорию `CATEGORY_HOME` первого приоритета, чтобы он считался базовым рабочим столом.

### Шаг 5. Реализация связки двух интерфейсов (ТВ <-> Рабочий стол)
1. **Стоковый Launcher3 остаётся включённым**, но вторым по приоритету.
2. В `LtvLauncher` закрепляем постоянную плитку «Рабочий стол», вызывающую `Intent: com.android.launcher3 / com.android.launcher3.Launcher`.
3. На Рабочем столе создаём постоянный ярлык «ТВ-режим», вызывающий `Intent: com.leanbitlab.ltvL / com.leanbitlab.ltvL.MainActivity`.

### Шаг 6. Брендирование «Зайка ОС» и замена кнопки «Пуск»
1. **В `build.prop`:**
   - `ro.build.display.id=Зайка ОС 1.0 (Media & Game Edition)`
   - `ro.product.name=ZaikaOS`
   - `ro.product.device=zaika_x86_64`
   - `ro.build.description=ZaikaOS 1.0 Media Edition`
2. **Кнопка «Пуск» в `SystemUI.apk`:**
   - Извлечение ресурса иконки меню «Пуск» (лого PrimeOS) из `SystemUI.apk` и замена его на векторную/PNG иконку мордочки зайки.
3. **Bootanimation:**
   - Уже готовая минималистичная покадровая контурная анимация жующего морковку зайчонка (uncompressed ZIP_STORED).

## ЧАСТЬ 4. План проверки и валидации

1. **Сборка нового ISO-образа `ZaikaOS-1.0-x86_64.iso`** со встроенными правками.
2. **Проверка в VirtualBox (эмуляция неттопа):**
   - Запуск VM `ayka` с подключённым ISO.
   - Проверка: автоматический старт установки на диск без клавиатуры через 3 секунды.
   - Проверка: чистая установка на `/dev/sda` за 30-40 секунд.
   - Отключение ISO от VM и старт напрямую с жесткого диска.
   - Замер скорости старта с диска (< 10 секунд).
   - Проверка ТВ-лаунчера: полный экран, отсутствие рамок DecoView, отсутствие экрана блокировки.
   - Проверка мыши: клик по плитке открывает приложение (SmartTube, HDrezka и т.д.).
   - Проверка переключения: клик на «Рабочий стол» открывает десктоп с зайкой на кнопке «Пуск», клик на «ТВ-режим» возвращает в LtvLauncher.
3. **Обновление физической флешки `D:`** для установки на целевой неттоп.
4. **Фиксация в приватном репозитории GitHub:** коммит обновленных скриптов и заливка проверенного финального ISO.
