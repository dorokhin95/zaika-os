# Техническое задание (ТЗ)
## Операционная система «Зайка ОС 1.0 (Media & Game Edition)»

### 1. Назначение системы
Создание легковесной операционной системы на базе Android-x86 / PrimeOS Classic для превращения неттопа / старого ПК в медиаприставку и ретро-игровую станцию для ТВ.

### 2. Целевое аппаратное обеспечение
- **Платформа:** Неттоп на базе AMD Brazos.
- **Процессор:** AMD APU Dual-Core E-450 (1.65 ГГц).
- **Графика:** Интегрированная AMD Radeon HD 6320.
- **Внутренний накопитель:** Жесткий диск `/dev/sda`.
- **Управление:** Только компьютерная мышь (клавиатура отсутствует).
- **Экран:** ТВ / монитор (1080p Full HD по HDMI / DVI).

### 3. Требования к загрузке и установке
1. **Автоматическая («тихая») установка:**
   - Загрузка с флешки без необходимости ввода с клавиатуры.
   - Полное автоматическое форматирование внутреннего накопителя `/dev/sda` (удаление Windows).
   - Автоматическая разметка (GPT/MBR) и установка системы в раздел `/dev/sda1` (ext4) с установкой GRUB.
   - По умолчанию таймер GRUB на флешке должен автоматически запускать автоустановку через 3-5 секунд.
2. **Безопасный тестовый режим:**
   - Возможность запуска в Live-режиме (без записи на диск) для отладки на ПК и в VirtualBox.

### 4. Визуальный стиль и брендинг
1. **Заставка меню загрузки (GRUB):**
   - Графическое фоновое изображение с логотипом «Зайка ОС» и зайчонком.
   - Меню на русском языке.
2. **Анимация загрузки (Boot Animation):**
   - Минималистичный контурный зайчик (line-art), держащий морковку и спокойно её грызущий.
   - Без мерцаний, плавная анимация (8 FPS).
3. **Исключение упоминаний сторонних ОС:**
   - Замена надписей «PrimeOS» и «Android» на «Зайка ОС» на всех этапах загрузки и в интерфейсе системы.

### 5. Пользовательский интерфейс и оболочка
1. **Главный экран (ТВ-лаунчер):**
   - Автоматический старт плиточного интерфейса (LtvLauncher), оптимизированного под мышь и ТВ.
   - Запуск строго в полноэкранном режиме (без оконных рамок DecoView с кнопками `_ [ ] X`).
   - Крупные плитки: Фильмы, YouTube, Игры, Браузер, Настройки, Рабочий стол.
2. **Многооконный рабочий стол:**
   - Возможность переключения на классический рабочий стол (PrimeOS Desktop) при необходимости.
3. **Локализация:**
   - Полный русский язык интерфейса по умолчанию (`ru_RU`).
   - Русская раскладка экранной клавиатуры.

### 6. Набор предустановленного ПО
1. **SmartTube x86:** Клиент YouTube без рекламы, адаптированный под ТВ-управление и архитектуру x86_64.
2. **HDrezka:** Приложение для просмотра фильмов и сериалов.
3. **AmneziaVPN:** VPN-клиент для обхода блокировок сетевых сервисов.
4. **Ретро-игры / Эмуляторы:** Поддержка ретро-консолей с управлением мышью/геймпадом.
5. **Браузер:** Легковесный веб-обозреватель с поддержкой мыши.

### 7. Система обновлений (OTA)
- Механизм обновления системного образа (`system.sfs`) по воздуху через GitHub Releases.
- Контроль версий через `version.json` с проверкой SHA-256.
- Сохранение пользовательских настроек и раздела `/data` при обновлении системы.
