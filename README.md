# 🐰 Зайка ОС 1.0 (Media & Game Edition)

Легковесная операционная система на базе ядра Linux и Android-x86, оптимизированная для работы в качестве медиа/игровой ТВ-приставки на неттопах и старых ПК (в частности, платформах **AMD Brazos / APU E-450 с графикой Radeon HD 6320**).

---

## Особенности системы
- **Визуальный стиль:** Индивидуальная заставка меню загрузки и покадровая анимация (зайчонок, жующий морковку).
- **Интерфейс медиаприставки:** Плиточный ТВ-лаунчер под пульт и мышь:
  - 🎬 **Фильмы** (HDrezka)
  - ▶ **YouTube** (SmartTube x86 без рекламы)
  - 🎮 **Игры** (поддержка ретро-консолей)
  - 🌐 **Браузер**
  - ⚙ **Настройки**
  - 🖥 **Рабочий стол** (мгновенный переход к многооконному режиму)
- **Русификация:** Полный русский интерфейс по умолчанию.
- **OTA-обновления:** Безопасное обновление «по воздуху» системного образа без потери пользовательских данных и установленных приложений.

---

## Архитектура OTA-обновлений
Каждое обновление публикуется в разделе **Releases** данного репозитория:
1. Система считывает актуальный файл `version.json`.
2. Если обнаружен новый релиз, приставка скачивает свежий `system.sfs` и сверяет SHA-256.
3. При перезагрузке система атомарно обновляется за 3 секунды, сохраняя весь раздел `data`.
